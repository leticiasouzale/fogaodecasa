# Fogão de Casa · Aprovação de conteúdos

Código-fonte da página de aprovação de conteúdos das redes sociais.

- `index.html`: a página (paleta e logo do Fogão de Casa).
- `pacote1-*`: vídeo (versão reduzida, 720p) e fotos do Pacote 1, para backup.

A versão ativa roda como artefato no Claude, que guarda os arquivos e as respostas dos clientes. Aberto fora do Claude, o `index.html` mostra só o layout, sem carregar conteúdos nem salvar aprovações.
